# Private original-video archive

In the private creator workspace or manager creative review, use **Get original download link**, then **Download exact original**. Revision history offers its own original when a corrected video has replaced it. Verified uploads also remain downloadable before entry submission. Public campaign pages expose processed playback only.

Convex checks the caller's current authenticated identity, active uploader access, campaign manager membership or active platform operator authority before issuing a grant, including an exact retry. The archive grant binds the verified upload identity, SHA-256 and byte count; an entry-context request additionally binds the exact entry and revision. Each issuance records actor, source, time, archive format version, optional entry revision and operation identity. Issuance records are not evidence that a transfer finished. Concurrent identical operations produce one audit row and the same expiry; a changed request needs a new operation identity.

The app returns a five-minute bearer link, never a private Blob URL or storage credential. Anyone holding that link can start the same exact original transfer before expiry. Revoking a role blocks new grant requests and retries immediately; it does not cancel an already-issued link or a copy already obtained. A new transfer at or after expiry is denied. A stream started before expiry can finish afterward. Keep issued links private. The response streams the archived object with an attachment filename, byte count and SHA-256 content digest, without buffering the file in server memory or writing server temporary files.

Original retention has no automatic expiry. The upload reservation's `expiresAt` limits intake only. Campaign dates, entry review status, movement of a revision into history and Mux processing or playback removal neither purge the object nor change its archive identity. This slice implements archive retrieval independently of those values; it does not implement campaign completion or entry withdrawal operations. Their later owners must preserve this invariant. Explicit administrator deletion, safeguards, restore and 30-day recovery belong to T07 and later lifecycle owners, and are not available here.

Run `npm run test:launch:backend` and `npm run test:launch:browser` for the bounded owned-run verification. The backend uses the actual isolated Convex binary with synthetic JWT identities, a private local file store and synthetic Mux transport. It exercises exact bytes, the actual 5,000,000,000-byte boundary, streamed hashing, current role changes, two clients, revision mismatch and tampering, expiry, missing intake terms, ended campaign dates, playback deletion and durable restart. Browser tests use two independent creator contexts and the creator/manager controls on desktop and mobile. Fixture-only time/role controls are copied only into the isolated deployment and never into application functions. Real Clerk session evidence remains T38; hosted Blob/Mux/Vercel access, bandwidth, limits and throughput remain T39. Local results do not certify these provider gates or future lifecycle operations.
